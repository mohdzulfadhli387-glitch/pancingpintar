# Pancing Pintar 2.4

App mancing peribadi dalam `index.html`.

- Simpan spot GPS dengan kategori Tuas, Unjam, Tukun, Jeti, Muara, Sungai, Tasik/Empangan dan Kolam.
- Simpan bacaan pasang/surut mengikut spot dan tarikh. Aplikasi tidak mendakwa ramalan automatik sebagai data rasmi; graf hanya menyambungkan bacaan yang dimasukkan. Rujuk jadual pasang surut rasmi PHN/Jabatan Laut.
- Kalendar Hijrah harian menggunakan kalendar Umm al-Qura pada browser (boleh berbeza sehari daripada tarikh rasmi rukyah Malaysia).
- Cuaca/keadaan laut melalui Open-Meteo, log tangkapan, statistik, dan eksport/import backup JSON.
- Spot, jadual air dan log disimpan dalam browser/peranti. Export backup sebelum clear data, buang app, tukar browser, atau tukar peranti.

Buka `index.html` sebagai halaman utama. Jika PWA lama masih terbuka, tutup app/tab dan muat semula laman dari hosting; cache service worker telah dinaik taraf ke `pancing-pintar-v24`.
